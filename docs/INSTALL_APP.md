# 앱 설치 매뉴얼 (SMS Gateway)

> 대상: 문자를 서버로 중계할 **전용 안드로이드 폰**
> 소요: 약 10분 / 삼성 One UI 기준 (타 제조사도 유사)

---

## ⚠️ 시작 전 꼭 읽기

1. **개인폰(뱅킹/페이/카톡 실사용)에 설치 금지.** 이 앱은 SMS·연락처 권한을 쓰기 때문에 구글 Play Protect가 "유해앱"으로 오탐 → 자동삭제하고, Play Integrity가 깨져 다른 앱(뱅킹 등)이 막힐 수 있습니다.
2. **반드시 전용 공기계**(중고폰 등)에 설치하세요.
3. 이 앱은 **플레이스토어에 없습니다** (SMS 게이트웨이는 구글 정책상 스토어 출시 불가). APK를 직접 설치합니다.

---

## 1단계 — Play Protect 끄기 (설치 전 필수)

앱을 설치하려 하면 Play Protect가 "악성코드 의심"으로 막습니다. 먼저 꺼야 합니다.

**플레이스토어 앱에서:**
1. Play스토어 → 우측 상단 **프로필 아이콘** 탭
2. **Play Protect** → 우측 상단 **⚙(설정)**
3. **"기기를 검사하여 보안 위협 감지"** OFF
4. **"유해할 수 있는 앱 개선..."** OFF

> 재부팅하면 구글이 다시 켤 수 있습니다. 설치·업데이트 직전에 다시 확인하세요.
> (관리자가 ADB 접근 가능하면 시스템레벨 영구차단도 가능 — TROUBLESHOOTING.md 참조)

---

## 2단계 — APK 설치

1. 폰 브라우저로 **배포된 APK 다운로드 링크** 접속 → APK 다운로드
2. 다운로드한 APK 탭 → "이 출처의 앱 설치 허용" 요청 시 **허용**
3. Play Protect 경고 뜨면 **"무시하고 설치"** / **"자세히 → 설치"**
4. 설치 완료 후 앱 실행

---

## 3단계 — 권한 허용 (앱 첫 실행)

앱이 순서대로 요청합니다. **전부 허용**:
- 문자(SMS) 권한
- 연락처 권한
- 알림 권한
- **알림 접근 권한** ← ★수신 핵심 (설정 화면으로 이동됨 → 앱 찾아서 ON)
- 배터리 최적화 제외 요청 → **허용**

> **알림 접근**이 이 앱의 문자 수신 방식입니다 (일반 SMS 수신방송이 아님).
> 이게 꺼져 있으면 문자를 못 받습니다.

---

## 4단계 — 서버 주소 설정

앱 설정 화면에서:
- **내부 서버 주소**: 예) `192.168.219.100` / 포트 `8379`
- **외부 서버 주소**(선택): 외부망에서 접속할 IP / 포트
- **내 전화번호**: 이 폰의 번호 입력

저장하면 앱이 서버에 등록되고 heartbeat를 보내기 시작합니다.

---

## 5단계 — 배터리 절전 예외 (★★★ 안 하면 밤에 죽음)

**이게 제일 중요합니다.** 삼성 배터리 절전이 유휴 시(특히 주말) 앱을 강제종료 → 문자 발송/수신 멈춤.

**설정에서 3곳 모두:**
1. 설정 → 앱 → (이 앱) → **배터리** → **"제한 없음"**
2. 설정 → 배터리 → **백그라운드 사용 제한** → **"미사용 앱 절전"** 목록에서 이 앱 **제외**
3. 설정 → 앱 → (이 앱) → **자동 실행 허용**

> 이 설정을 안 하면 폰이 몇 시간~하루 방치 후 앱이 죽습니다.
> 죽으면 서버의 감시 크론이 텔레그램으로 알려줍니다 (TROUBLESHOOTING.md).

---

## 설치 확인

- 앱 화면에 "수신/발송 대기 중" 표시
- 서버 관리화면에 이 폰이 **온라인**으로 뜨고 last_poll 갱신
- 다른 폰에서 이 폰으로 문자 보내 수신 테스트
- 서버에서 이 폰으로 발송 테스트

모두 되면 설치 완료입니다.
