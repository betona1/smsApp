# 개인정보 처리방침 (Privacy Policy) — SMS Gate

**앱 이름:** SMS Gate
**패키지:** com.bitic.smsgateway
**최종 수정일:** 2026-07-20

---

## 1. 개요

SMS Gate("본 앱")는 사용자의 안드로이드 기기에서 수신·발송되는 문자(SMS/MMS)를
**사용자가 직접 지정한 서버**로 중계하는 **셀프호스팅 문자 게이트웨이** 앱입니다.

**중요:** 본 앱은 개발사(bitic)의 서버로 어떠한 데이터도 전송하지 않습니다.
모든 데이터는 **사용자가 앱 설정에 입력한 자체 서버로만** 전송됩니다.
개발사는 사용자의 문자·연락처·전화번호 등 어떤 개인정보도 수집·저장·열람하지 않습니다.

---

## 2. 수집·사용하는 정보

본 앱은 기능 제공을 위해 다음 정보에 접근합니다. 모든 정보는 **사용자 지정 서버로만**
전송되며, 앱 자체는 이를 영구 저장하지 않습니다.

| 정보 | 접근 이유 | 전송 대상 |
|------|-----------|-----------|
| **수신 문자(SMS/MMS) 내용·발신번호** | 문자를 서버로 중계 | 사용자 지정 서버 |
| **발송 문자 내용·수신번호** | 서버가 요청한 문자를 대신 발송 | 통신사(실제 발송) |
| **기기 전화번호** | 기기 식별(어느 폰에서 온 문자인지) | 사용자 지정 서버 |
| **연락처(선택)** | 발신번호를 이름으로 표시(사용 시) | 로컬 표시용 |

본 앱은 광고 SDK, 분석 SDK, 위치정보, 결제정보를 일절 사용하지 않습니다.

---

## 3. 권한 사용 목적

| 권한 | 목적 |
|------|------|
| RECEIVE_SMS / READ_SMS | 수신 문자 감지·중계 |
| SEND_SMS | 서버 요청에 따른 문자 발송 |
| RECEIVE_MMS | MMS(사진문자) 수신 중계 |
| READ_CONTACTS | (선택) 발신번호를 연락처 이름으로 표시 |
| READ_PHONE_STATE / NUMBERS | 기기 전화번호 자동 감지 |
| 알림 접근 (Notification Listener) | 문자 알림 기반 수신 감지(핵심 동작 방식) |
| INTERNET | 사용자 지정 서버와 통신 |
| FOREGROUND_SERVICE / WAKE_LOCK | 백그라운드에서 안정적 동작 |
| RECEIVE_BOOT_COMPLETED | 재부팅 후 자동 재시작 |

---

## 4. 데이터 보관 및 전송

- 본 앱은 문자 데이터를 기기에 **영구 저장하지 않습니다** (중복발송 방지용 임시 식별자 제외).
- 모든 전송 대상은 **사용자가 앱에 직접 입력한 서버 주소**입니다.
- 서버에 저장된 이후의 데이터 관리·보안 책임은 **해당 서버 운영자(사용자)**에게 있습니다.
- 개발사는 전송 경로·서버에 관여하지 않으며 데이터를 볼 수 없습니다.

---

## 5. 제3자 제공

본 앱은 사용자 지정 서버 외 **어떠한 제3자에게도** 데이터를 제공·판매하지 않습니다.
문자 발송 시 통신사를 경유하는 것은 SMS 표준 동작이며 별도 데이터 공유가 아닙니다.

---

## 6. 대상 사용자

본 앱은 **업무용 전용 기기**에 설치하여 운영하는 것을 전제로 합니다.
개인 상용폰(뱅킹/결제 사용)에는 설치를 권장하지 않습니다.
