# 앱 등록·배포 준비 자료 (SMS Gate)

> 앱 등록에 필요한 메타데이터·자산 모음 + 등록 채널 현실.

---

## ⚠️ 먼저: 등록 채널 현실

**구글 플레이스토어 등록 불가** — SMS 권한 앱은 "기본 문자앱(default SMS handler)"만
허용하는 정책이라, 문자 게이트웨이는 심사에서 **반려**됩니다. (동종 앱 SMSGate/textbee/
httpSMS 전부 플레이스토어 미등록, 직접배포)

**현실적 등록·배포 채널:**

| 채널 | 가능? | 비고 |
|------|-------|------|
| 구글 플레이스토어 | ❌ | SMS 정책상 반려 |
| **직접 APK 배포** | ✅ (권장) | 자체 다운로드 페이지 + 깃헙 릴리스 |
| **F-Droid** | ✅ | 오픈소스 등록(소스 공개 필요), 심사 관대 |
| 삼성 갤럭시 스토어 | △ | SMS 정책 상대적으로 유연, 시도 가치 있음 |
| 원스토어(국내) | △ | 국내 SMS 앱 사례 존재, 문의 필요 |

→ 아래 자산(아이콘·스크린샷·설명·개인정보방침)은 **모든 채널 공통으로 필요**하므로 미리 준비.

## 짧은 설명 (80자 이내)

> 핸드폰 문자를 내 서버로 중계하는 셀프호스팅 SMS 게이트웨이

## 긴 설명

> SMS Gate는 안드로이드 기기의 문자(SMS/MMS) 수신·발송을 **사용자가 지정한 서버**와
> 연동하는 셀프호스팅 문자 게이트웨이입니다.
>
> **주요 기능**
> - 수신 문자를 지정 서버로 실시간 중계 (알림 접근 기반)
> - 서버에서 요청한 문자를 대신 발송 (실제 전송결과 확인)
> - 다중 기기 운영, heartbeat 기반 상태 모니터링
> - 텔레그램 수신 알림 연동
> - 내부/외부 서버 자동 페일오버
>
> **특징**
> - 개발사 서버로 데이터를 보내지 않음 — 100% 자체 서버로만 전송
> - 업무용 전용 기기 운영에 최적화
>
> ※ 본 앱은 전용 기기 설치를 전제로 하며, 서버 구축이 필요합니다.

| 데이터 안전 신고서 | 폼 작성 | ⬜ SMS/연락처 사용목적 기재(방침 내용 그대로) |

## 남은 준비 작업

1. **앱 아이콘 커스텀 디자인** — 현재 안드로이드 기본 아이콘. "SMS Gate" 브랜드 아이콘 512×512 제작 필요.
2. **스크린샷 정리** — `screenshots/`의 실제 번호(01027...)·내부IP(192.168...)를 일반값으로 마스킹하거나 재촬영.
3. **개인정보방침 호스팅** — `PRIVACY_POLICY.md`를 공개 URL로 (GitHub Pages 등) → 등록폼에 URL 기입 + 운영자 이메일 채우기.
4. **피처 그래픽** — 등록 채널이 요구 시 제작.
